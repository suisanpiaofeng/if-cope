## 一、项目是什么

**IF.Cope**（原名 IF.Learn）：校园 AI 学习工作站，本地 Demo 已完成并可日常使用。

定位：学生把课程资料（PDF/Word/PPT/MD/代码/图片/网页/粘贴文本）丢进来 → 解析分块 → 向量检索问答（带来源引用）→ AI 生成产物（笔记等）→ 产物进 AIGC 类目、可下载、可拖拽分类。

**与同类（NotebookLM 克隆）的差异点：内置 Agent。对话模型不只是问答，还能通过工具直接操作应用**（新建类目、移动文件、生成笔记、查库结构），即"AI IDE"式交互（参考 TRAE/Cursor 的 System Context + Function Calling 模式）。

### 运行方式

```bash
cd iflearn-demo          # 注意：文件夹名仍是 iflearn-demo（见"未尽事项"）
npm run dev              # 端口 3777
# 浏览器 http://localhost:3777
```

## 三、已完成功能清单

### 工作台
- 四栏布局：侧栏 │ 资源树 │ 预览/编辑区 │ 对话栏；三处分界线全部可拖拽调宽（含资源/成果纵向分界）
- 直角紧凑风格（代码块保留圆角）
- **类目树**：AIGC（内置不可删，存产物）+ 普通类目 + 未归类；三态复选框（全选/类目即全选）
- **拖拽**：文件↔类目移动（PATCH）、拖文件进对话框（=勾选，并集作为上下文）、外部文件拖入即上传
- 上传弹窗（NotebookLM 式）：上传文件 / 网站（自动爬取正文+真实标题）/ 复制的文字

### 预览与编辑
- Markdown：左编辑右实时渲染；代码/txt：打开即 CodeMirror 编辑器（语法高亮、Ctrl+S 保存→写回文件+更新 sha256+重建向量索引）
- PDF 原生 iframe、DOCX 转 HTML、图片、网页正文爬取展示
- 缩放：图片**裸滚轮缩放**（0.2×–5×）+ 按住拖动 + 双击复位；其他内容 Ctrl+滚轮（每标签独立记忆）

### 对话与 Agent（本轮核心）
- 勾选 ∪ 拖入 = 检索上下文；都没选 = 全部资源；**发送后选中态全部重置**
- 引用编号 [n] 可点击跳转原文
- **环境自知**：System Prompt 注入应用结构说明 + 实时资料库状态（类目/资料/产物清单、对话选中项）
- **Function Calling**：模型可调用 6 个工具真实操作数据库；工具活动以紫色进度条实时展示（⏳/✅/❌）
- 实测通过："新建类目叫X，然后告诉我有哪些类目" → 模型连续调 create_category + list_library → 落库 → 流式汇报

### 产物
- **所有产物默认落 AIGC**（categoryId 兜底 null）
- 下载到本地（.md）：文件栏 ⤓ 按钮 + 预览页工具条两处入口
- AIGC ↔ 普通类目双向拖拽（PATCH，含 400 校验）

### 本地嵌入（免配置检索）
- 默认走本地 bge-small-zh-v1.5（embeddingDimension=384 已写入设置）
- 首次下载经 hf-mirror；已知坑：fastembed 首次下载结束时 rename 偶发 ENOENT（文件实际完整），**重试一次解析即成功**
- 切换嵌入来源时维度不符 → 明确报错并要求重建索引（设置页有重建逻辑）

### 索引 2.0（2026-10-22 重写，对标成熟开源实现）
- **分块** `lib/chunk.ts`：递归分层分隔符（LangChain 式：段落→句子→硬切）+ 句子永不截断（LlamaIndex 式）+ **标题路径 heading 注入嵌入**（Contextual Retrieval 思想）+ 500 字符预算（卡 bge 512 token 上限）+ 保底1块 + 单源上限200块
- **混合检索** `lib/retrieval.ts`：FTS5 trigram 关键词路 + 向量语义路 → **RRF 融合**（Khoj/Quivr 式 hybrid）；FTS 表 `chunks_fts` 由 db.ts 触发器自动同步，业务层无需维护
- **Schema**：`chunks.heading` 列 + `chunks_fts` 虚表，db.ts 模块加载时自动迁移+存量回填
- **音频 STT** `lib/parse/audio.ts`：本地 whisper-tiny（`@huggingface/transformers`），mp3/m4a/wav/aac/flac 直接入库检索；`STT_MODEL`/`STT_LANG` 环境变量可换模型/语言
- ⚠ **网络坑**：本机 Node fetch 到 hf-mirror 会 `UND_ERR_CONNECT_TIMEOUT`（curl 却通）→ **模型一律用 curl 预下载到 `data/models/`，transformers 走 `env.localModelPath` 离线加载**（v4 不读 HF_ENDPOINT！）；换 STT 模型需先 curl 下 `data/models/{org}/{model}/`

## 四、关键设计决策（不要推翻）

1. **模型调用只有一个出口**：`modelGateway.ts`（地址/Key/额度）+ `embed.ts`（嵌入）。业务代码禁止直接拼 baseUrl。
2. **一期计费 = 学生自带中转站 Key**，不改 new-api fork，不做第二套钱包（详见对接契约）。
3. **登录/多租户留空**：正式接入走 IF.Link 的 Logto + Accounts UUID + 独立 `learn` PG 库（对接契约文档），本地单用户不提前实现。
4. **存储抽象**：上线换对象存储（MinIO/COS）只改 `storage.ts` 4 个函数，业务无感。
5. **嵌入是索引契约**：换嵌入模型必须重建全部向量，代码已强制校验维度。
6. **AIGC 语义**：只收产物；资料只能进普通类目/未归类（Agent 提示词里已声明此边界）。
