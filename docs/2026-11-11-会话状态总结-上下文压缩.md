# IF.Cope 会话状态总结（上下文压缩 · 2026-11-11）

> 本文档是 2026-11-10~11 长会话的完整状态压缩。新会话/新上下文读本文即可恢复全部工作状态。

## 1. 项目是什么

**IF.Cope**（仓库 `suisanpiaofeng/if-cope`，Private，分支 `classroom-v2`）——校园 AI 学习工作站，本地优先：
- **工作台**：资料库（上传/解析/向量化）+ RAG 问答 + 便签生成 + AI 归类
- **文献翻译**（PDF 双语）、**解题答疑**（知识地图 + QA 卡片）、**工具库**、**课堂**（CVS 录播）、**设置**
- 技术栈：Next.js 15 / TS / better-sqlite3 / Tailwind / @xyflow/react；本地 ONNX 嵌入 + DeepSeek（deepseek-flash，**推理型模型**）；数据在 `data/`（SQLite + uploads + models）
- 端口：3777（App）/ 3778（CVS 反代，含会话保活）

## 2. 本次会话完成的全部工作

- UI 重设计：三栏（课程/课时窄栏/播放器）、搜索弹窗（当前学年优先+自动补拉分页）、课程删除（连课时缓存）、换机位续播（记住进度/暂停态）、错误分类提示（401/5xx/502）

- 修 EADDRINUSE、`.next` 互砸（dev/build 不能同时跑）、搜索排序、反代 Transfer-Encoding 双头 bug

### Agent 内核（一期）
- `todo_write` 工具 + `agent_todos` 表 + **任务面板**（人机共写清单：状态循环/双击编辑/删除）

- 健壮性：工具分类超时/重试、模型 429/5xx 退避重试、断流续跑 2 次、重复调用/预算护栏

### Agent 个性化（二期）

- **上下文工程**：`foldHistory` 历史分层截断（4000 token 预算、保最近 2 轮）；**用量展示**（usage_ledger 聚合）

### 工作台
- **产物（知识地图/笔记）接入对话**：勾选/拖拽/绿色胶囊/内容注入（qa-map 转问答卡摘要）——修了"勾了没用"的断链 bug

### 知识地图（大改+智能化）
- **树 → 纯 DAG 边表**（`QaMapEdge`：可汇聚/兄弟连/双向）；旧数据自动迁移；防环
- **map_link 一次调用**（路由+标注合一），**内容型标注**（「前提：线性时不变假设」，禁裸通用词）；一次可产 3 条连线（创建即汇聚）
- **手动连线弹窗**（留空→AI 补生成标注）、边编辑按边 id、SVG 线可点选
- **地图操作工具化**：`update_map_edges`+`update_card` 挂在 /api/ask——"重新梳理连线"直接改边表不生成卡、极紧密内容补充进原卡、模型三选一自主决策
- **智能化功能**：◎AI 体检（诊断+一键修复）、删卡智能修复（AI 建议接续上下游）、重复卡合并（AI 融合）、**撤销/重做（Ctrl+Z/Y）**、⊹自动布局、标签缩放自适应（<0.4 缩放隐藏）

## 3. 关键决策记录

| 决策 | 内容 |
|---|---|
| 推理模型预算 | deepseek-flash 的 reasoning_content 吃 token，LLM 小任务 max_tokens 必须 ≥8000（400/2000 都翻过车——这是"标注没特征"的真正根因） |
| JSON 解析 | 推理模型输出要用括号平衡提取（`extractJsonObject`），贪婪正则会拼非法 JSON |
| 数据命名 | 对话实体=thread（thread_id）；产物=artifact；资源=source |
| 提示词治理 | 可改可恢复默认；chat 只开放追加（护动态骨架）；空覆盖=回默认 |
| qa-map 模型 | 纯图无主父（DAG）；relFrom=目标卡相对源卡（源端徽标）、relTo 反之 |
| 会话保活 | Cookie 存 settings 表、5 分钟续命；错误分类 401→重登、5xx→平台故障、502→网络 |
| TDD 惯例 | verify-*.mjs 裸 Node 跑纯逻辑（相对扩展名导入 + allowImportingTsExtensions） |

## 6. 环境注意事项

- **dev server**：`npm run dev`（3777）；`npm run build` 与 dev 互斥（共享 .next 会互砸）；后台测试服要记得关
- **代理**：git 配置了 127.0.0.1:7897（Clash 类），没开时用 `git -c http.proxy= -c https.proxy= push` 直连
- **验证**：`npm run verify` + `npm run typecheck`；运行时冒烟用真模型 curl /api/chat 或 /api/ask
- **Token 卫生**：会话中发过两个 GitHub token，已建议 revoke
- **数据备份**：`data/ifcope.db` 是全部数据；WAL 大时可 `PRAGMA wal_checkpoint(TRUNCATE)`
