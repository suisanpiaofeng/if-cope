> 状态：**已与用户评审通过（对话评审）**，待实施计划（writing-plans）。
> 本文取代 `课堂专区-架构规格-20261024.md`（v1，六阶段管线方案，已被否决——重管线复杂度高且 ASR 兜底前提不成立）。
> 参考项目：flash-summary（六阶段/时间锚/体检思想）、cvs-replay-notes-skill（三段式/字幕优先/幻觉过滤/真题分层）——**只取思想，不搬管线**。

## 1. 背景与用户需求

用户三需求（2026-10-28 对话确认）：

1. **可看课程视频**：在 IF.Cope 应用内直接看 CVS（东南大学课程平台）回放。
2. **可总结笔记，连贯、贯穿一整门课、适合期末突击**：双层结构——逐课笔记（保细节）+ 期末复习手册（按主题重组、必考/常考/了解分层）。
3. **与其他功能对接**：笔记进 RAG（工作台对话/检索可引用）+ 导出 Markdown。

### 1.1 关键事实（用户 2026-10-28 提供）

- 平台 **AI 字幕课后 12 小时内必出**；偶有错别字但不影响理解——**字幕是唯一转写原料**。
- 平台自带 AI 概要质量低——不用作原料，最多当辅助参考（一期不用）。
- 结论：v1 的「音轨抓取 + 本地 ASR + 幻觉过滤管线」整条砍掉。

### 1.2 用户决策

| # | 决策 | 影响 |
|---|---|---|
| D1 | 看课 = **反代内嵌**（上次已验证原型） | 本机反代剥 `X-Frame-Options`，iframe 内嵌官方页；只透传不存储 |
| D2 | 笔记 = **逐课笔记 + 期末手册** 双层 | 两层各自独立生成，手册可重生成 |
| D3 | 对接 = **RAG 回流 + 导出** | 不做自测题、不做课时问答（一期） |
| D4 | **登录走网页本身，零 Playwright**（用户提议，已推演可行） | 反代弹顶层窗口完成 CAS 官方登录；Cookie 由浏览器托管（localhost 域），反代改写 Set-Cookie 使其落在 localhost |
| D5 | **按钮驱动轻管线**（否决六阶段后台管线） | 无断点续跑/后台队列；状态一个字段；坏一处不连坐 |
| D6 | 数据模型带 `user_id`（沿 v1 D1） | 本地单用户，将来多人/服务器演进留门 |

## 2. 总体架构

```
┌─ 浏览器 ────────────────────────────────────────────┐
│ /classroom 页                                        │
│  ├─ iframe ──→ http://localhost:3778/…（反代内嵌回放）  │
│  └─ fetch ──→ http://localhost:3778/…（经反代调官方接口）│
│                Cookie 由浏览器自动带上（localhost 域）    │
├─ Next.js 服务端（3777）──────────────────────────────┤
│  /api/classroom/*  → 读写 SQLite；调 modelGateway 生成笔记│
├─ 反代（3778，随应用启动）─────────────────────────────┤
│  转发 cvs.seu.edu.cn + CAS 域：                        │
│   · 剥 X-Frame-Options / CSP 响应头                    │
│   · 改写 Set-Cookie（去 Domain/Secure → 落 localhost）   │
│   · 改写重定向 Location（跨域 CAS 链映射回反代）           │
│   · 改写响应体里的绝对地址（HTML/JS 内写死的官方域名）       │
│   · 前端调用放行 CORS（Allow-Credentials 指向 3777）      │
└────────────────────────────────────────────────────┘
```

**信任边界**：反代只在 `localhost` 监听；只转发用户本人会话；不落盘任何响应体中的媒体/凭据。

### 2.1 登录与会话生命周期

1. 用户点「登录 CVS」→ `window.open("http://localhost:3778/__login")`（顶层窗口，无 X-Frame 问题）。
2. 反代把 `__login` 302 到官方登录页（经反代改写的 CAS 地址）；用户正常输账号密码。
3. CAS 回跳官方站时，反代改写 Set-Cookie（剥 `Domain=*.seu.edu.cn`、剥 `Secure`）→ 浏览器把会话 Cookie 存到 `localhost:3778`。
4. 此后 iframe 内嵌、前端 fetch（`credentials: "include"`）全部自动带 Cookie。
5. **凭据托管在浏览器**：重启应用免登录；会话过期时前端探测到 401/登录页特征 → UI 提示重新登录。服务端**不存**任何凭据。

### 2.2 反代实现要点

- 单文件模块 `src/lib/classroom/revProxy.ts`，`instrumentation.ts` 随应用启动监听 3778（dev/prod 均生效）。
- 官方域名 + CAS 域名集中在常量区（真机联调只改这里）；重定向链按域名→路径前缀映射（如 `/__cas/…` → `auth.seu.edu.cn/…`）。
- 响应体改写仅对 `text/html`/`javascript` 类型做绝对地址替换（官方域名 → 反代地址）；媒体流（m3u8/ts/mp4）只转发不改写。
- 健壮性：无 Cookie、校园网外、上游挂——一律返回明确错误提示（502 + 文案），**绝不让异常打挂主进程**（v1 教训：`undefined` 头会抛 uncaughtException，须 delete 而非赋 undefined，且 handler 整体 try/catch）。

## 3. 数据模型（SQLite，全部带 `user_id`）

```sql
classroom_courses(       -- 一门课 = CVS 一个教学班
  id PK, user_id, cvs_course_id, name, term, teacher,
  meta_json, created_at, updated_at,
  UNIQUE(user_id, cvs_course_id)
)
classroom_lessons(       -- 一节课 = 一个回放
  id PK, course_id FK, user_id, cvs_lesson_id, title, seq,
  replay_url, vod_status,      -- -3=转码中
  duration_sec, note_status,   -- none|done|failed + error_note
  error_note, created_at, updated_at,
  UNIQUE(user_id, cvs_lesson_id)
)
classroom_notes(         -- 逐课笔记（每课时一条）
  id PK, lesson_id FK, user_id,
  content_md,                 -- 带时间戳的结构化 Markdown
  model, source_id,           -- 回流 RAG 的 source 外键
  created_at, updated_at, UNIQUE(lesson_id)
)
classroom_digests(       -- 期末复习手册（每课程一条，可重生成）
  id PK, course_id FK, user_id,
  content_md, model, source_id, created_at, updated_at,
  UNIQUE(course_id)
)
```

- `note_status` 是课时上唯一的状态字段（D5：无多阶段状态机）。
- 笔记/手册生成后 `content_md` 登记为 `sources`（type=笔记）+ 切块向量化进现有 RAG；`source_id` 记回以便重生成时替换（删旧 chunks 重建）。

## 4. 内容服务 API

| 端点 | 说明 |
|---|---|
| `GET /api/classroom/courses` | 课程树（含课时数/已生成数） |
| `POST /api/classroom/courses` | 登记课程（CVS 链接解析 teclId + 名称） |
| `DELETE /api/classroom/courses/[id]` | 删课程（级联） |
| `GET /api/classroom/lessons?courseId=` | 课时列表（note_status/vod_status） |
| `POST /api/classroom/lessons` | 保存课时目录（**前端经反代拉官方接口后提交**，服务端不直连 CVS） |
| `POST /api/classroom/lessons/[id]/note` | 生成逐课笔记（输入：字幕 segments 或手动文本） |
| `GET /api/classroom/lessons/[id]/note` | 读逐课笔记 |
| `POST /api/classroom/courses/[id]/digest` | 生成/重生成期末手册 |
| `GET /api/classroom/courses/[id]/digest` | 读期末手册 |

**分工原则**：需要官方会话的请求（课时目录、字幕）由**前端经反代**发起（Cookie 在浏览器侧），拿到结果提交到我们自己的 API 落库；LLM 生成、落库、RAG 回流在服务端。

**登录态探测**：服务端看不到浏览器 Cookie，由前端直接 `fetch("http://localhost:3778/__whoami", { credentials: "include" })` 探测反代（反代在官方会话有效时返回标识、失效时返回 401），UI 据此显示「已登录/未登录」。反代启动状态由服务端通过 `GET /api/classroom/proxy-info` 提供。

### 4.1 逐课笔记生成

- 原料：该课时 AI 字幕（前端经反代拉取的带时间戳 segments）；无字幕时手动贴文本兜底。
- 一次 LLM 调用产出结构化 Markdown：本节要点（带 `[mm:ss]` 时间锚）、关键概念、公式/结论、疑难点。
- 走 modelGateway 单出口；未配置模型时降级 mock（沿本项目既有纪律，UI 链路可完整演示）。
- 生成后自动登记进 RAG（sources type=笔记）。

### 4.2 期末复习手册生成

- 原料：该课程全部 `note_status=done` 的逐课笔记。
- LLM 一次调用产出：按**主题重组**（同一知识点跨课次合并）、**必考/常考/了解**分层、考点出现课次索引（「第 3、7 讲都讲了」）。
- 依赖逐课笔记数量 ≥1；不足时仍可生成并在文首标注覆盖范围。
- 可一键重生成（覆盖 + RAG 重建）。

## 5. 前端专区（`/classroom`，视频优先）

- 侧栏新增「课堂」入口；三栏：课程树（含「📖 期末复习手册」入口）/ 课时列表（note_status 徽标 + 字幕未出的灰态）/ 右栏主区。
- 右栏双标签：**▶ 视频**（默认，iframe 内嵌反代回放页；未爬链接课时给手粘兜底输入框）/ **✎ 笔记**（逐课笔记阅读，时间戳可点跳官方页定位）。
- 顶部操作：登录 CVS（弹层）、生成本节笔记、生成期末手册、导出 Markdown。
- 任务运行态：按钮级 busy + 明确错误横幅；无全局任务面板（D5）。

## 6. 与现有功能对接

| 对接 | 实现 |
|---|---|
| RAG 回流 | 笔记/手册 `content_md` → sources（type=笔记）→ 现有 chunk/embed/FTS 链路；工作台对话、检索即可引用 |
| 导出 | 笔记/手册 Markdown 下载，出口带「请勿公开转发」提示 |
| 模型配置 | 复用设置抽屉的 modelGateway，不新增配置项 |

一期**不做**：自测题生成、课时问答、全文搜索、B 站源、多用户。

## 7. 合规披露层（硬要求，沿 v1 §8 与两参考项目）

- **首次使用拦截声明**（勾选同意才进专区）：非官方工具、与学校无隶属授权；个人学习用途；只用本人账号、只处理有权访问内容；不做批量抓取、不二次分发；凭据只存浏览器本地、无遥测；课程资料属学校教学资源请勿公开转发；AI 输出可能出错以原始内容为准。
- 导出出口均带「请勿公开转发」提示。
- 声明文本单一事实源、版本号钉住。
- 多用户演进前提（D6）：将来每人本人 CAS 登录、按用户隔离；**公开部署前必须获得学校同意**（沿 verify/cvs-proxy.js 注记）。本期不实现多用户。

## 8. 风险与未决

| 风险 | 缓解 |
|---|---|
| CAS 跨域登录链经反代的改写细节（重定向/相对路径/跳转检测） | 域名与改写规则集中常量区；**真机联调是 M1 的验收核心**；保底方案 = 登录退化为「提示用户手动在官方页登录后粘贴 Cookie」（一行兜底代码，不做爬虫） |
| 官方页面/接口变动（绝对地址、字幕接口路径） | 反代改写规则 + 前端接口常量集中，单点修 |
| 字幕 12h 未出 / vod_status=-3 转码中 | UI 明确提示「稍后重试」；手动贴文本兜底路径 |
| LLM 幻觉 | 笔记声明「以原始内容为准」；时间锚格式在 prompt 中约束（一期不做自动核验） |
| 反代打挂主进程 | v1 教训已吸收：头空删、handler 全 try/catch、上游错误降级为 502 提示 |
| 校园网外使用 | 全链路明确报错提示（需校园网/VPN），无静默失败 |

**未决**（实施前/联调期确认）：
1. 官方字幕接口路径与响应结构（M2 真机联调确认）。
2. CAS 登录页是否自带跳转检测影响反代改写（M1 真机联调确认）。

## 9. 里程碑

- **M1 看课**：反代（3778）+ 网页登录 + iframe 内嵌回放；`/classroom` 骨架、课程登记、合规声明拦截。**真机验收核心**。
- **M2 逐课笔记**：课时目录拉取落库 + AI 字幕拉取 + 逐课笔记生成 + RAG 回流。
- **M3 期末手册**：手册生成/重生成 + 导出 + 收尾（声明钉版、交接文档同步）。

每步：tsc + build + CDP 冒烟（声明拦截/内嵌/按钮链路）→ 规范 commit；真机验证点集中在 M1（登录链）与 M2（接口联调），常量区设计保证现场可快速修正。
