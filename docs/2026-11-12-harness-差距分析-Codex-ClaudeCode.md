# IF.Cope → AI 编程 Harness 差距分析（vs Codex CLI / Claude Code / OpenHands）

> 2026-11-12。目的：把 IF.Cope 从"校园 AI 学习工作站"补齐为可用的 AI 编程 harness。
> 图例：✅ 已具备 / 🟡 部分具备 / ❌ 缺失。优先级：P0=可用性底座（先做）/ P1=体验完善 / P2=生态向后置。

## 总览对照表

### 一、Skill 系统
