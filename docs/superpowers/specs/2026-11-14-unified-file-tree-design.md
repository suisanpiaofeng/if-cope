# IF.Cope 统一文件空间（OpenNote 内核 + 学习增强）· 架构规格（2026-11-14）

> 背景：用户指出资料库/工作区两个文件列表功能重合、概念混乱（2026-11-14 反馈）。经讨论确定：以 OpenNote 的"一切皆文件、一棵树"为内核，把资料库降级为索引层，合并为唯一文件空间，并叠加学生学习场景的增强。

## 1. 目标与设计原则

1. **一棵文件树 = 唯一真源**（OpenNote 内核）：文件夹+文件；位置=路径；零"搬进仓库"动作；拷走目录=完整备份
2. **能力即开关，不是动作**：「问答索引」是文件上的开关（解析/向量化是开关的实现细节），入不入库文件都不动
3. **AI 就地干活**：读写改删全部作用于树（确认卡保护）；"AI 改上传资料"不需要专用工具，`edit_file` 即可
4. **学习增强**：类型/课程维度、课程空间模板、学习产物归位、引用溯源、全文+语义双搜索

## 2. 核心模型与定位规则

### 2.1 概念映射（旧 → 新）

| 旧概念 | 新模型 |
|---|---|
| 资料库（uploads 散列存储 + 解析入库） | 文件树中的文件 + 「📚 问答索引」开关（chunks/向量指向文件路径） |
| 工作区（data/workspace） | 就是这棵树的根（不再作为独立区域展示） |
| 产物（artifacts 孤立成果区） | 落进树的文件（带"AI 产物"类型徽标），产物列表=筛选视图 |
| 勾选资料提问 | 勾选树中"已入库"的文件 |

### 2.2 定位规则（唯一一套，覆盖上传/生成/解析）

| 动作 | 文件位置 | 索引状态 |
|---|---|---|
| 上传 | 默认 `资料/`（上传弹窗可改路径） | 自动入库（弹窗可取消） |
| AI 新建/生成文件 | 任务指定的路径（脚本→`项目/`、笔记→`资料/` 等，模型在 system prompt 中被告知惯例） | 默认不入库（树行一键「入库」） |
| 解析入库 | **原地不动** | 挂索引（chunks/向量入库，指向路径） |
| 取消入库 | 原地不动 | 删 chunks（文件保留） |
| 编辑已入库文件（人或 AI） | 原地不动 | **自动重建索引** |
| 删除已入库文件 | 文件删除 | 索引随删（同既有 removeSource 语义） |

> 一句话：位置=路径、资料库=索引开关、生成默认不入库、上传默认入库可关。

## 3. 存储与迁移

- 根目录：`data/workspace/`（沿用 `IFCOPE_WORKSPACE_DIR`/settings.workspacePath 覆盖）
- **sources 表加 `path` 列**（树相对路径；NULL=未迁移的旧散列文件）
- **一次性迁移**（启动时或设置页按钮触发，幂等）：
  1. `uploads/<storage_name>` → `资料/<标题去重>.<ext>`（重名追加 `-2`）
  2. `sources.path` 填新路径；文件内容不动 → **chunks/向量全部有效，不重建**
  3. 迁移完成打标（settings `filesMigrated`），失败可重跑（按 path IS NULL 过滤）
- 上传管线改为直写树路径（不再 saveFile 散列名）；`PUT /api/sources/:id`（编辑重建索引）改为按 path 读写
- **编辑联动**：凡写文件的路径带 source 记录（`/api/workspace/file` PUT、agent `write_file`/`edit_file`）→ 异步重建该文件索引（复用既有重建函数）

## 4. 学习增强（5 项）

1. **类型徽标与筛选**：文件类型推断（讲义 PDF/笔记 md/错题本/代码/产物），树行显示徽标；顶栏筛选条：全部 / 📚 已入库 / 按类型 / 按课程（文件夹）
2. **课程空间模板**：右键文件夹或按钮「新建课程空间」→ 生成 `高数/讲义/作业/错题本/复习计划` 骨架
3. **产物归位**：AI 产物（复习笔记/知识地图导出/翻译）生成后落进指定文件夹（默认 `资料/`，可在生成弹窗选）；产物列表改为树中 `type=artifact` 文件的视图（数据仍在 artifacts 表，文件为导出态；双向同步以文件为准）
4. **引用溯源**：问答引用 [n] → 点击打开树中源文件并定位到对应块位置（预览滚动高亮）
5. **双搜索**：顶栏搜索框同时搜文件名/全文（既有）与语义提问（走检索）；下拉分组展示「文件 / 问答结果」

## 5. UI（资源栏收敛为一棵树）

```
[文件]  搜索框＋筛选条（全部📚|讲义|笔记|代码|产物，课程下拉）
 ├─ 高数/
 │   ├─ 讲义/极限.pdf        📚 12块  [PDF]
 │   ├─ 错题本.md            📚 3块   [笔记]
 │   └─ 复习计划.md          [产物]
 ├─ 项目/
 │   └─ main.py              [代码]
 └─ .ifcope/（AGENTS.md、hooks.json——配置区，置灰）
```

- 行操作（悬停）：预览/编辑、📚 入库|出库、下载、删除（二次确认）
- 拖拽：文件/文件夹移动；拖外部文件=上传到该目录（自动入库，可关）
- 对话勾选区 = 树中已入库文件（沿用 selected 机制，数据源换成树）
- 上传按钮/拖拽复用现有 UploadModal，加"保存到"路径与"自动入库"勾选

## 6. API 变化

| 端点 | 变化 |
|---|---|
| `POST /api/sources` | 上传直写树路径 + path 落库；body 增 `path?`、`autoIndex?` |
| `POST /api/sources/:id/index`（新） | `{ on: boolean }` 入库/出库（出库删 chunks） |
| `GET /api/files/tree`（新） | 树+每文件元数据（type/索引状态/chunk 数/path） |
| `PUT /api/workspace/file` | 写后联动重建索引（path 命中 source 时） |
| `POST /api/files/migrate`（新） | 触发一次性迁移，返回迁移清单 |
| `/api/preview/[id]` | 改按 path 读（兼容旧 id 查询） |

## 7. 不做的事

- 多用户/协作/权限（保持本地单人）
- 文件版本历史（Git 式）
- 云同步
- 产物双向同步的复杂冲突处理（以文件为准，artifacts 表仅存元数据）

## 8. 分批实施

| 批次 | 内容 |
|---|---|
| **P3-1 存储统一** | sources.path、上传直写树、迁移脚本+幂等、编辑联动重建索引、`/api/sources/:id/index` 开关 |
| **P3-2 UI 单树** | 树+筛选条+类型徽标、行操作（入库开关/预览/下载/删除）、上传弹窗路径+开关、对话勾选换数据源 |
| **P3-3 学习增强** | 课程空间模板、产物归位+产物视图、引用溯源定位、双搜索 |

## 9. 验收

1. 迁移后旧资料全部出现在 `资料/`（标题命名、重名去重），问答引用与迁移前一致（向量块未重建）
2. 树里任意文件可开/关问答索引；关闭后提问不再引用，文件仍在
3. AI 在对话里修改一份已入库讲义（确认卡 diff、放行）→ 问答引用即为新内容
4. 上传弹窗可选路径与自动入库；AI 新建文件默认不入库、一键入库可用
5. 「新建课程空间」生成骨架；产物落进所选文件夹并在产物视图可见
6. 引用 [n] 点击跳源文件定位；搜索框文件/语义双结果
7. `npm run verify` + `npm run typecheck` 全绿（新增 verify-file-tree 等纯函数脚本）
