# IF.Cope 知识地图大改 · 图化与语义连线 · 架构规格（2026-11-10）

> 状态：**待用户评审**。评审通过后进入 writing-plans 拆实施计划。
> 上游：`docs/superpowers/specs/2026-11-10-agent-phase2-personalization-design.md`（Prompt 可配置机制，本规格复用）。
> 用户决策（2026-11-10）：**纯图无主父（真 DAG，边全部平等）；手动连线弹窗填两端关系词；标注用「内容型标注」**（如「傅里叶变换的收敛条件」而非「追问」）；知识路由与关系标注**合并为一次调用一个提示词**。

## 1. 背景与目标（三个病灶，代码核实 2026-11-10）

| 病灶 | 根因 |
|---|---|
| 无法汇聚（多分支不能汇入同一节点） | `QaMapNode.parentId` 单亲外键——**树**结构，连线从 parentId 派生，无独立边表 |
| 兄弟连线两线不能共存 | `solve/page.tsx onConnect` 覆盖目标节点 parentId（`{...n, parentId: conn.source}`），新线顶掉旧线 |
| 路由/标注两次调用、标注词没特征 | `chooseParent`（map_router）与 `describeRelation`（map_rel）分两次调用，只给问题前 120 字；提示词留了"拿不准用通用词"逃生口 → 满屏"追问延伸/上文依据" |

目标（G1-G3）：

- **G1 图化**：数据模型树 → 纯 DAG（独立边表、边平等无主父）；任意多入边（汇聚）/出边（分支）/兄弟连线；两节点间同向不重复、反向允许；
- **G2 连线交互**：手动拖线建立边（防环保留）时**弹窗填两端关系词**（可留空 → 显示无标注）；边编辑面板按**边 id** 改词/断开（不再是节点 id）；
- **G3 提示词合并 + 内容型标注**：`map_router` + `map_rel` 合并为 **`map_link`** 一个 key 一次调用；基于两卡**问题+回答内容**生成有特征的内容型标注；新问题无显式父卡时 AI 可一次返回**多条连线**（创建即汇聚）。

零回归：问答/引用标注/追问按钮/卡片拖拽缩放/多地图/导入导出照旧；旧地图数据自动迁移。

## 2. 数据模型（qaMapTypes.ts）

```ts
export type QaMapEdge = {
  id: string;            // `${from}->${to}` 或 uuid
  from: string;          // 源卡 id（原"父"）
  to: string;            // 目标卡 id（原"子"）
  relFrom?: string;      // 源端标注：目标卡相对源卡的关系（如「深入拆解」）
  relTo?: string;        // 目标端标注：源卡相对目标卡的关系（如「上文依据」）
};

export type QaMapNode = {
  id: string;
  round: number;
  title: string;
  question: string;
  answer: string;
  citations?: QaMapCite[];
  x: number; y: number; w?: number; h?: number;
  // parentId/relation/relParentEnd/relChildEnd 全部废弃（迁移后不再写入）
};

export type QaMapData = { title: string; nodes: QaMapNode[]; edges: QaMapEdge[] };
```

**迁移（`normalizeQaMap`）**：导入旧格式（有 parentId 无 edges）时逐节点生成 `edge{from: parentId, to: id, relFrom: relParentEnd ?? relation, relTo: relChildEnd}`；新格式校验：from/to 必须指向存在的节点（悬空边丢弃）、同向重复边去重、`id` 冲突自动改名。`round` 保持存储值不变。

**纯函数更新**：
- `ancestorChain(nodes, edges, nodeId)`：改走**全部入边**并集向上收集（多父时全部祖先入链、去重、上限 8 条），供追问上下文；
- `nextNodePosition(nodes, edges, sourceId)`：新卡放源卡右侧，同源出边数决定纵向堆叠；
- `hasCycle(nodes, edges, from, to)`：新增——连线前防环（BFS 自 from 向上/自 to 向下判可达）。

## 3. G3 提示词合并（map_link，一次调用）

**调用时机**：`/api/ask` 新问题**无显式父卡**时一次调用；有显式父卡（追问按钮）时也调（生成该边的两端标注）。

**输入**：新问题 + 全部卡片（`id｜标题｜问题｜回答摘要 80 字`）+ 上一轮连线上下文（若有）。

**输出**（JSON 一次拿全）：

```json
{"links":[{"to":"卡片id","relFrom":"深入拆解：傅里叶变换的收敛条件","relTo":"上文依据：级数展开基础"}]}
```

- `links` 可为空（全新独立话题）或多条（**汇聚/多向关联**——创建即汇聚）；
- 追问场景 `to` 固定为所追问的卡，只产标注。

**标注规则（内容型，替换旧"2-6 字关系词"）**：
- 格式「关系类型：内容特征」，类型 2-4 字（前提/推导/例证/对比/反驳/应用/特例/背景…），内容特征 6-14 字**点名具体概念**（如「前提：线性时不变假设」「例证：方波分解成正弦」）；
- 必须基于**回答内容**提炼（输入含摘要），禁止只看问题下空泛结论；
- **禁止**单独使用「追问/延伸/相关/依据」这类无特征词（写入提示词硬规则）；
- 生成失败/不合规则 → 该边**不显示标注**（不再 fallback 灌水）。

**Prompt key 变更**：`prompt_overrides` 新增 `map_link`；`map_router`/`map_rel` 从 `PROMPT_DEFAULTS`/设置页移除（残留行无害不动）。设置页 Prompt 列表变 4 项：对话追加/解题/复习笔记/知识连线。

## 4. G2 手动连线交互（solve/page.tsx）

1. 拖源卡右侧锚点 → 目标卡：`hasCycle` 防环（环则 toast 提示拒绝）；
2. **弹窗**（新增 `EdgeDialog`）：显示两卡标题，两个输入框「源端标注（目标卡相对源卡）」「目标端标注」，可留空；确定 → 追加边（同向已存在则提示"已有连线"并拒绝）；
3. 点击边线/标注 → 边编辑面板（现有面板改造）：改两端标注 +「断开连线」（按边 id 操作）；
4. 反向连线（B→A 且已有 A→B）允许，SVG 箭头方向区分。

**追问按钮**（onFollowUp）：新卡与源卡建立一条边，标注由 `map_link` 自动产出（弹窗不打扰）；`explicitParentId` 语义改为 `sourceId`（连线源，不再是父）。

## 5. 渲染（EdgesOverlay.tsx）

- 边列表改从 `QaMapData.edges` 读（不再从 parentId 派生）；
- 多入边/出边自由共存；两端标注徽标挂边 id；标注为空则不渲染徽标（只画线）；
- 起终点锚点选择：源卡右缘中点 → 目标卡左缘中点；目标在源左侧时自动改用左→右缘（线不穿卡）。

## 6. 不做的事（本期范围外）

- 自动布局重排（力导向/分层布局）——保持手动拖拽 + 落位启发式；
- 边样式自定义（颜色/虚线/粗细）；
- 子图折叠/聚焦视图、路径高亮；
- 标注词受控词库/双语；
- 地图间连线、跨地图引用。

## 7. 风险与对策

| 风险 | 对策 |
|---|---|
| 旧地图迁移损坏 | `normalizeQaMap` 双格式兼容 + 迁移只增边不改节点；导出仍是 JSON 可回滚 |
| 多父后追问上下文爆炸 | `ancestorChain` 去重 + 上限 8 条；超限取最近 round 的祖先 |
| `map_link` 单次调用返回多 links 出幻觉连错 | links 上限 3 条；`to` 不在卡片表即丢弃；温度 0 |
| 内容型标注过长挤压 UI | 徽标截 20 字 + 悬停全文；SVG 徽标宽度自适应 |
| 提示词 key 迁移影响用户自定义 | `map_router`/`map_rel` 覆盖行保留不动（无人读）；`map_link` 新增默认 |

## 8. 验收标准

1. 三个分支能**汇聚**到同一节点（手动拖 3 条入边共存）；兄弟之间互连、双向互连共存；
2. 手动拖线弹窗填词 → 边两端显示自定义标注；点边改词/断开生效；连线成环被拒绝并提示；
3. 新问题 AI 判定"综合两个分支"时一次产出 **2 条连线**（创建即汇聚），标注为内容型（点名概念，非"追问"）；
4. 追问按钮：新卡自动连源卡，标注内容型；追问上下文包含多祖先（多父卡场景）；
5. 旧地图导入：连线/标注完整迁移为边；往返导出导入无损；
6. 零回归：问答/引用/卡片拖拽缩放/多地图/设置页 Prompt 列表正常；`tsc` + verify 脚本通过。
