# Harness P2 改造 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** P2：收尾质量包（deferred minors 清偿）、工作区 zip 打包下载、MCP stdio 客户端与 Agent 接入、Hooks 生命周期钩子。

**Architecture:** 纯函数先行（zip/rpc/hooks-match/retry 助手，verify 直测）；zip 自写 stored 格式零依赖；MCP 连接池挂 globalThis（沿用 confirm 模式教训）；hooks 复用 executeCommand 的受限执行但豁免 commandPolicy（用户显式配置）、黑名单仍硬拒。

**Tech Stack:** 不变；零新依赖。

**Spec:** `docs/superpowers/specs/2026-11-12-harness-p0-design.md` §9

## Global Constraints

- 零新依赖；UI 中文；每任务收尾 `npm run verify && npm run typecheck` 全绿 + commit（`feat(harness): ...`）
- zip：stored（method 0）、CRC32 标准多项式 0xEDB88320、条目路径 `/` 分隔、目录下载 ≤500 文件/≤20MB
- MCP：stdio 换行分隔 JSON-RPC 2.0；请求 30s 超时；连接池 globalThis；进程死自愈重连；mcp_call_tool 恒 reversible（需确认）
- Hooks：`.ifcope/hooks.json`；pre 非零退出拦截工具；post 旁路；hook 命令过 classifyCommand 黑名单（deny 不跑）；执行 10s 超时/safeEnv/stripAnsi
- skills 缓存 TTL 3s；`listSkills(refresh = false)`；writeSkill/deleteSkill 内置失效
- 抽纯函数一律相对扩展名导入（`./workspace.ts` 式），保持 verify 可直测

## Review Focus

1. **zip 二进制正确性**（CRC32 已知值、结构签名、条目数、解压兼容）→ verify-zip-fn 字节级断言 — T2
2. **MCP 帧粘包/半包**（一条消息分两次到达、一次两条、超长行）→ parseMessages 累积缓冲断言 — T3
3. **MCP 子进程死亡自愈**（server 崩溃后下一次调用重连成功而非永久失败）— T4 冒烟
4. **hooks 拦截边界**（pre exit1 拦截、post 不阻塞、黑名单命令 hook 也拒、match glob 匹配）→ verify-hook-fn + 冒烟 — T5
5. **缓存一致性**（TTL 内外部改文件 → 重载按钮 refresh=true 立即生效）— T1 verify/冒烟
