# Harness P1 改造 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** P1：diff 确认卡/编辑器 diff、会话分支/回滚、长任务自愈、统一错误处理、命令策略收紧（沙箱强化）。

**Architecture:** 两个纯函数库先行（diff.ts / errors.ts，verify 直测）；确认卡与编辑器复用 lineDiff；分支/回滚走 messages 表复制/删除（新 API）；错误分类模板统一喂给模型与 UI；commandPolicy 三档在 classifyTool 前置闸断。范围裁剪（zip 打包下载→P2、容器沙箱→命令策略收紧）已记录在 spec §7。

**Tech Stack:** 不变；零新依赖。

**Spec:** `docs/superpowers/specs/2026-11-12-harness-p0-design.md` §7

## Global Constraints

- 零新依赖；UI 文案中文；每任务收尾 `npm run verify && npm run typecheck` 全绿 + commit（`feat(harness): ...`）
- diff 行级 LCS；输入换行归一化（\r\n→\n）；输入超 5000 行两侧截断并在尾注标注
- 错误分类五类：network/timeout/validation/denied/unknown；`friendlyError` 输出「分类标签 + 原信息 + 建议」
- commandPolicy：`normal`（现状）/ `readonly`（仅只读白名单，其余 deny）/ `off`（run_command 一律 deny）；默认 normal
- run_command 子进程 env 白名单：PATH/SystemRoot/SystemDrive/TEMP/TMP/HOME/USERPROFILE/COMSPEC/PATHEXT（win32）或 PATH/HOME/TMPDIR 等（posix）
- 会话回滚为不可逆操作：UI 红色二次确认 + 服务端无需确认（UI 把关，与工作区删除同语义）

## Review Focus

1. **diff 正确性/性能**（空行、CRLF、超长文件、完全相同/完全不同）→ lineDiff 归一化+截断，verify 全样本 — T1
2. **分支/回滚边界**（beforeMessageId 不存在/首条消息/回滚后 todos 与历史一致性）→ API 400/404 + 冒烟 — T4
3. **错误分类误判**（"fetch failed"→network、"timeout 工具 x"→timeout、"路径超出工作区"→validation、"安全策略拒绝"→denied）→ verify 样本钉死 — T2
4. **commandPolicy 绕过**（`echo a && rm x` 在 readonly 下必须 deny——含写类段即拒）→ verify 组合样本 — T6
5. **输出污染**（ANSI 转义/超长输出）→ stripAnsi + 既有 20k 截断 — T6

### Task 1: `src/lib/agent/diff.ts` 行级 diff（纯函数）

**Files:**
- Create: `src/lib/agent/diff.ts`
- Create: `scripts/verify-diff-fn.mjs`
- Modify: `package.json`（verify 链）

**Interfaces:**
- Produces:
  - `type DiffLine = { type: "same" | "add" | "del"; text: string; oldNo?: number; newNo?: number }`
  - `lineDiff(oldText: string, newText: string): DiffLine[]` — LCS 行 diff；\r\n 归一化；两侧超 5000 行截断并保留尾部截断标记行（type:"same", text:"……（diff 输入已截断）"）
  - `formatDiff(lines: DiffLine[], maxLines: number = 120): string` — 统一格式 `+ 新增行` / `- 删除行` / `  相同行`，超量尾注

- [ ] **Step 1: verify-diff-fn.mjs 失败断言**：完全相同→全 same；单行修改→1 del+1 add 相邻；纯新增/纯删除；空文本；CRLF 归一化；5001 行截断标记；formatDiff 前缀与截断
- [ ] **Step 2: FAIL → 实现 diff.ts（LCS DP；行数乘积 >25e6 时降级为「整块替换」防卡死）**
- [ ] **Step 3: verify PASS；verify 链接入；全绿；commit `feat(harness): 行级 diff 纯函数（P1 T1）`**

### Task 2: `src/lib/agent/errors.ts` 错误分类/ANSI 清洗（纯函数）

**Files:**
- Create: `src/lib/agent/errors.ts`
- Create: `scripts/verify-error-fn.mjs`
- Modify: `package.json`（verify 链）

**Interfaces:**
- Produces:
  - `type ErrorKind = "network" | "timeout" | "validation" | "denied" | "unknown"`
  - `classifyError(msg: string): ErrorKind` — 关键词表：fetch/ECONN/ENOTFOUND/socket→network；timeout/超时/ETIMEDOUT→timeout；路径超出工作区/不能为空/非法/不存在/必须是→validation；安全策略/学生未确认/拒绝/禁用→denied；其余 unknown
  - `friendlyError(kind, msg): string` — 格式 `[类别] 原信息` + 建议（network→检查网络/稍后重试；timeout→缩小范围或调大 timeout_ms；validation→按提示修正参数；denied→换安全方式或询问学生；unknown→重试或反馈）
  - `stripAnsi(s: string): string` — 剥 `\x1b[...` 转义

- [ ] **Step 1: verify-error-fn.mjs 失败断言**（Review Focus 3 样本 + stripAnsi + friendlyError 含建议且保留原信息）
- [ ] **Step 2: FAIL → 实现 → PASS → 全绿；commit `feat(harness): 错误分类/友好提示/ANSI 清洗纯函数（P1 T2）`**
