# IF.Cope 课堂学习专区 · 架构规格（2026-10-24）

> 状态：**待评审**。评审通过后进入实施计划（writing-plans）。
> 本文是课堂专区子系统的唯一架构规格；与交接文档冲突时以本文为准。

## 1. 背景与目标

### 1.1 由来
- 交接文档 roadmap 一期承诺：左侧栏「课堂」入口 → 专区界面（回放列表 + 推荐区 + 助手卡片）→ 回放点击 → 助手下载。
- `verify/` 已论证：iframe 内嵌 CVS 被 X-Frame-Options + 内网域名双重封死；cvs-proxy.js 反代原型自带「公开部署前须学校同意」注记。
- **校内服务器即将购入**：服务器本身在校园网内，`cvs.seu.edu.cn`(10.64.86.180) 直接可达，使原先出局的「服务端爬取/抓流」路线部分复活。

### 1.2 参考项目经验（已调研）
- **flash-summary**（Electron/SEU 录播+B站）：六阶段任务流水线、每阶段 checkpoint 断点续跑、任意阶段可取消；教师流取音频无音轨回退屏幕流；感知哈希抽关键帧去重；**字幕优先无字幕才 ASR**；时间锚引文逐条核验、核不上降级；一键重生成复用已存转写+关键帧；同一 JSON 投影五视图；文件治理（转写完删音频、>24h 缓存清理）。
- **cvs-replay-notes-skill**（Agent/CVS 回放）：**三段式笔记**（全面课堂笔记带时间戳 / 考点归纳分层+必做题+自测 / 课程通知置顶）；AI 字幕优先本地/云转写兜底；幻觉过滤（循环句折叠、片尾套话删）；往年真题 AI 打标 → 考点热度榜 → 按进度出《本周题单》；courses.json 登记一条命令增量跑；幂等可续跑（vodStatus -3 转码中半小时后再跑）。
- **两者共同合规姿态**：非官方、个人学习用途、只用本人账号、只处理有权访问内容、不批量抓取、不二次分发、凭据只存本地、无遥测。

### 1.3 用户决策（本规格前提）
| # | 决策 | 影响 |
|---|---|---|
| D1 | **现在不能部署，将来必然多人用** | 本地优先（同交接文档 demo 模式）；数据模型从第一天带 `user_id`，架构预留多用户/Logto/PostgreSQL 演进 |
| D2 | **只做笔记，不碰视频** | 不存储/不服务/不内嵌视频；回放播放跳官方页；媒体足迹收敛到「转写所需音轨」+（二期可选）关键帧 |
| D3 | **先出架构规格** | 本文即规格，评审通过后拆实施计划 |

### 1.4 目标
把「课程回放 → 三段式学习笔记 → 可检索/可问答/可导出」打通成一条本地优先、多用户就绪的管线，并在 IF.Cope 加一个「课堂」专区承载阅读与加工。**专区不是孤岛：生成的笔记回流现有资料库，进入既有对话/检索链路。**

## 2. 范围

### 2.1 一期做
- 「课堂」左侧栏入口 + 专区页（课程树 / 课时列表含处理状态 / 三段式笔记阅读 / 全文搜索 / 导出）。
- 爬取管线：CAS 登录（受控浏览器）→ 爬回放列表+课时元数据 → AI 字幕优先、无则取音轨转写 → 生成三段式笔记 → 体检返修 → 落库。断点续跑、幂等、可取消。
- 内容服务 API：课程/课时列表、笔记读取、转写读取、全文检索、课时问答（复用 chat+sources）。
- 合规披露层：首次使用拦截声明、每处导出出口提示。
- 与现有集成：笔记登记为 `source` 进 RAG；考点归纳接测验/知识地图；导出接 artifacts。

### 2.2 一期不做
- 视频存储/服务/内嵌播放（D2）。播放走官方页（路线 A 兜底）。
- 关键帧/多模态笔记（需视频访问，二期，且受 D2 约束）。
- 往年真题匹配 / 本周题单（二期，需真题库接入）。
- 推荐区 / 助手卡片（二期，先跑通笔记主链）。
- B 站源（一期只做 CVS）。
- 云端同步 / 多租户计费。

## 3. 总体架构（分层）

```
┌─ 爬取/笔记管线（worker，异步）─────────────────────┐
│  S1 会话登录 → S2 爬列表/元数据(+AI字幕)            │
│  → S3 取音轨转写(仅无AI字幕) → S4 生成三段式笔记     │
│  → S5 体检/返修 → S6 落库+索引                       │
│  每阶段 checkpoint；幂等(lesson 去重)；可取消可重试  │
├─ 内容服务（Next.js API Route）─────────────────────┤
│  courses / lessons / notes / transcript / search /  │
│  ask(课时问答) / pipeline 触发与状态                 │
├─ 前端专区（/classroom）────────────────────────────┤
│  课程树 + 课时列表(状态) + 三段式笔记阅读            │
│  (时间戳点击跳官方回放) + 搜索 + 导出(MD/Anki/导图)  │
├─ 回流集成 ────────────────────────────────────────┤
│  笔记 → source(进RAG) / 考点 → 测验·知识地图         │
└──────────────────────────────────────────────────┘
```

- **worker 本地形态**：现在作为 Next.js 内的队列进程（child_process / 内存队列）在用户机器跑，需校园网/VPN。
- **worker 服务器形态**：同一 worker 代码搬到校内服务器变成常驻任务队列，加多用户 auth。**代码不变，仅宿主与鉴权变。**

## 4. 数据模型（SQLite 起步，多用户就绪）

所有课堂表带 `user_id`（本地 demo 恒为默认用户；将来接 Logto 用 Accounts UUID）。

```sql
-- 课程（一门课 = CVS 一个教学班）
classroom_courses(
  id PK, user_id, cvs_course_id, name, term, teacher,
  meta_json,          -- 学期/院系/自定义术语提示词等
  created_at, updated_at
  UNIQUE(user_id, cvs_course_id)
)
-- 课时（一节课 = 一个回放）
classroom_lessons(
  id PK, course_id FK, user_id, cvs_lesson_id, title, seq,   -- seq 排序
  replay_url,          -- 官方回放页 URL（去签名，仅跳转用）
  vod_status,          -- 平台转码态(-3 转码中等)
  duration_sec, source_kind,  -- ai_subtitle | asr
  stage,               -- 当前阶段 S0..S6，断点续跑依据
  stage_state,         -- pending|running|done|failed
  error_note, checkpoint_json,  -- 各阶段 checkpoint 与断点数据
  created_at, updated_at
  UNIQUE(user_id, cvs_lesson_id)
)
-- 转写稿（带时间戳，供时间锚与问答上下文）
classroom_transcripts(
  id PK, lesson_id FK, user_id,
  segments_json        -- [{start,end,text}] 或行式
)
-- 三段式笔记（结构化 JSON + Markdown 双存）
classroom_notes(
  id PK, lesson_id FK, user_id,
  kind,                -- full | exam | notice（三段各一条）
  content_md,          -- 归纳后 Markdown（阅读/导出用）
  content_json,        -- 结构化（时间锚/分层/必做题，投影视图用）
  model, verified,     -- 生成模型；时间锚核验态
  created_at
)
-- 二期：关键帧/讲义资产
classroom_assets(
  id PK, lesson_id FK, user_id, kind,  -- keyframe | ppt
  path, ts
)
-- 二期：真题库与考点
classroom_exam_bank(...) / classroom_exam_tags(...)
```

- **笔记回流现有 RAG**：三段笔记生成后，`content_md` 另登记进现有 `sources/chunks/vectors`，使「课堂笔记」像普通资料一样可被工作台对话/检索引用。
- **幂等键**：`user_id + cvs_lesson_id`；重跑先查 stage 从断点续，不重复已完成阶段。

## 5. 爬取/笔记管线（六阶段）

| 阶段 | 做什么 | checkpoint / 断点 | 复用参考 |
|---|---|---|---|
| S1 会话 | Playwright 受控浏览器完成 CAS 登录；会话凭据 **DPAPI/本机密钥加密**落盘，重启免登录；校园域名绕过系统代理 | 存加密 cookie/JWT | flash-summary / cvs-skill（受控浏览器+本地凭据） |
| S2 爬元数据 | 拉课程回放列表 + 课时目录；解析加密 teclId；检测 vod_status；**优先抓平台 AI 字幕** | 存列表快照 | cvs-skill（teclId 解析、AI 字幕优先） |
| S3 转写 | 仅当该课时无 AI 字幕：取音轨（教师流，无音轨回退屏幕流），120s 分片转写、片偏移拼接、静音跳过、HTTP Range 断点续传；幻觉过滤 | 存带时间戳转写稿 | flash-summary（分片+回退+Range）、cvs-skill（幻觉过滤） |
| S4 生成笔记 | 转写(+可选 AI 字幕摘要) → LLM 生成**三段式**：全面笔记(带时间戳)/考点归纳(必考·常考·了解分层+必做题+自测)/课程通知 | 存三段 content_json | cvs-skill（三段式结构） |
| S5 体检返修 | 时间锚引文逐条核验（对不上转写则降级）；幻觉/重复过滤；内容体检不过自动返修一次 | 存 verified 态 | flash-summary（时间锚核验+体检返修） |
| S6 落库+索引 | 写 classroom_* 表；笔记 content_md 登记为 source 进现有 RAG 索引 | 全部落库 | 本项目（ingest/chunk/embed） |

- **驱动**：S1–S6 串行；每阶段完成写 `stage`+`checkpoint_json`；失败留在原阶段可重试；任意阶段可取消（清理中间媒体）。
- **增量**：按课程一条命令/一键触发，只处理未达 S6 的课时；刚下课 vod_status=-3 的延后重试。
- **文件治理**：音轨转写完即删、中间媒体 >24h 清理（沿用参考项目纪律）。
- **模型出口**：S3 转写与 S4 生成全部走现有 `modelGateway.ts` 单出口（对话模型/独立转写配置），不新增第二套配置。

## 6. 内容服务 API（新增 `/api/classroom/*`）

| 端点 | 说明 |
|---|---|
| `GET /api/classroom/courses` | 当前用户课程树（含课时数/已处理数） |
| `POST /api/classroom/courses` | 登记课程（CVS 链接 + 可选术语提示词） |
| `GET /api/classroom/lessons?courseId=` | 课时列表（含 stage/stage_state，前端显示处理状态） |
| `GET /api/classroom/lessons/[id]/notes` | 三段式笔记（full/exam/notice） |
| `GET /api/classroom/lessons/[id]/transcript` | 带时间戳转写稿 |
| `GET /api/classroom/search?q=` | 跨课时全文检索笔记+转写 |
| `POST /api/classroom/ask` | 课时问答（上下文严格限本课时：转写+笔记，复用 chat+sources） |
| `POST /api/classroom/pipeline` | 触发某课时/某课程管线（入队），返回任务态 |
| `GET /api/classroom/pipeline/[taskId]` | 任务阶段/进度/失败原因 |

## 7. 前端专区（`/classroom`）

- 左侧栏新增「课堂」入口（`Sidebar.tsx` NavItem）。
- 三栏：课程树 / 课时列表（阶段进度轨道 + 状态徽标：排队·运行·失败·完成）/ 笔记阅读区。

- 任务运行态：阶段轨道 + 进度 + 取消/重试（参考 flash-summary 六阶段可见）。

## 8. 合规披露层（沿两参考项目，硬要求）

- **首次使用拦截声明**（勾选同意才进专区）：非官方工具、与学校无隶属授权；个人学习用途；只用本人账号、只处理有权访问内容；不做批量抓取、不二次分发；凭据本地加密、无遥测；课程资料属学校教学资源请勿公开转发；AI 输出可能出错以原始内容为准。
- **只写能核对的事实**：每条声明在源码有依据；无自动上报；导出出口均带「请勿公开转发」提示。
- **多用户演进的合规前提**（D1 将来多人用）：届时每位用户以本人 CAS 账号登录、笔记按用户/课程显式授权隔离；**公开部署/镜像/转发能力前必须获得学校同意**（verify/cvs-proxy.js 既有注记）。本期不实现多用户，但数据模型与披露层按此设计。
- 声明文本单一事实源，版本号钉住（参考 flash-summary DISCLAIMER 纪律）。

## 9. 与现有 IF.Cope 集成

- **笔记回流 RAG**：S6 把 `content_md` 登记为 `source`，课堂笔记即可被工作台对话/知识地图引用。
- **考点归纳 → 测验/知识地图**：三段式的「考点+自测」可一键生成测验产物或知识地图卡片。
- **课时问答**：复用 `/api/chat` 的 sources 检索模式，上下文限本课时。
- **导出**：接现有 artifacts 落库与下载。
- **模型配置**：不新增配置，复用对话/翻译模型分接口（设置抽屉）。

## 10. 部署演进（本地 → 服务器多用户）

| 维度 | 现在（本地 demo） | 将来（校内服务器） |
|---|---|---|
| 宿主 | 用户机器（需校园网/VPN） | 校内服务器（常驻，恒在校园网） |
| 数据库 | SQLite（`data/`） | 独立 PostgreSQL（IF.Link 契约建议 `learn` 库） |
| 用户 | 默认单用户（`user_id` 占位） | Logto Traditional Web + Accounts M2M，Accounts UUID 作业务主键 |
| 爬取 | 本地 worker（用户触发） | 服务器任务队列（多用户任务隔离） |
| 凭据 | 本机加密 | 每用户独立加密会话，服务端隔离 |
| 模型 | 用户自配 Provider | 中转站 Key（自带），或服务器统一 Provider |

**不变式**：worker 代码、管线阶段、数据 schema 字段、内容服务 API 契约——本地与服务器一致，仅宿主/鉴权/存储引擎替换。

## 11. 风险与未决

| 风险 | 缓解 |
|---|---|
| CVS 接口/页面变动 | 爬虫集中在 worker 单模块，S2 解析器可独立回归；受控浏览器抗 JS 变动优于纯 HTTP |
| CAS 登录风控（频率限制/锁定） | 串行单账号、低频、退避；只处理本人课程；声明提示账号风险 |
| 转写成本/时长 | 字幕优先（平台有 AI 字幕则零转写）；音轨仅无字幕时取 |
| 音轨下载合规 | 仅转写所需、用完即删、不存储不服务（D2） |
| LLM 幻觉 | S5 时间锚核验 + 体检返修 + 声明「以原始内容为准」 |
| Playwright 依赖体积 | 懒加载（仅 S1/S2 需要时 import），沿本项目内存纪律 |
| 多用户迁移 | 表已带 `user_id`；SQLite→PG 走 migration；Logto 接入在部署期而非重构期 |

**未决**（实施前需再确认）：
1. Playwright 版本与 headless 环境在 Windows 本机的稳定性（需 spike 验证 CAS 全流程）。
2. 三段式笔记的 `content_json` 结构化 schema（时间锚/分层/必做题字段）——在 S4 实现前细化。
3. 校内服务器规格（CPU/GPU/磁盘）决定是否将来可选本地 ASR（faster-whisper）而非纯云转写。

## 12. 里程碑（供实施计划拆解）

- **M0 骨架**：`/classroom` 页 + 侧栏入口 + 空态；`classroom_*` 表建表迁移；合规首次声明拦截。
- **M1 爬取**：S1 登录 + S2 爬列表/元数据 + vod_status；课时列表落库与状态显示。
- **M2 转写**：S3 音轨转写（字幕优先兜底）+ 幻觉过滤；转写稿落库。
- **M3 笔记**：S4 三段式生成 + S5 体检返修；笔记阅读视图（时间戳跳回放）。
- **M4 集成**：S6 回流 RAG + 课时问答 + 全文检索 + 导出。
- **M5 收尾**：断点续跑/取消/重试打磨 + 文件治理 + 声明层钉版 + 交接文档同步。

每个里程碑完成 → tsc+build+CDP 冒烟 → 按规范 commit；M0–M2 即可形成「能看到课时和转写」的最小可用切片。
