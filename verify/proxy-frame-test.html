CVS 内嵌显示框验证 · 反代方案 cookie 入手

iframe 指向的是 http://localhost:3778/...（自家反代），响应头里的 X-Frame-Options 已被剥掉， Cookie 由 Node 服务端代带 → 浏览器侧没有任何限制。iframe 里显示的就是 CVS 真实页面。
使用步骤
  1. 浏览器登录 cvs.seu.edu.cn → F12 → Network → 刷新 → 点第一个请求 → Request Headers → 右键复制 Cookie: 整行的值。
  2. 粘贴保存到 verify/cvs-cookie.txt（就一行，不要带 "Cookie:" 前缀也行，脚本都能处理）。
  3. 运行 node verify/cvs-proxy.js，看到「反代已启动」后刷新本页。
  4. iframe 里能看到登录后的页面 = 成功；若提示未登录 = Cookie 过期/不全，重取一次。
判定：iframe 内能看回放播放页 → 「应用内嵌回放窗」成立，可直接做成 IF.Cope 课程学习区的正式形态； Cookie 有效期实测（大概率几小时~1 天）决定产品里要做"一键重登/自动续期"。
