CVS 视频流验证 · 路线 B（应用内置 <video> 播放器）

原理：<video src> 媒体元素不受 CORS 限制，即使平台没开跨域头也能跨域播放。 本页验证「拿到流地址后能否直接在自己页面里播」，这是"内置显示框看回放"仅存的浏览器侧路线。
⚠ 合规边界（同 skill）：仅在线播放授权范围内的回放，不下载、不落盘、不传播媒体文件。
人工判定：
结论
判定项结果
流地址来源待测
播放结果待测
音频轨待测
地址是否过期/要鉴权待测
结论待测后自动给出
怎么拿到流地址（3 步）
  1. 登录 cvs.seu.edu.cn，打开某节课的播放页，按 F12 → Network → 筛选 XHR。
  2. 找 course_vod_urls_new（或含 vod/url 的响应），在 Response 里复制视频地址数组。
    ⚠ skill 结论：courseVodViewList 里 viewNum=1 是屏幕录像（常无音轨）；课堂音频在 viewNum=5（aac）或 viewNum=3（pcm_alaw）——只测一个地址不够，两个都要试。
  3. 粘到本页测试。若报跨域/403，把「Network 里该请求的 Request Headers（Authorization/Cookie/Referer）」记入结果，这决定服务端或扩展要不要代带鉴权头。
